## Global Constraints

- English only.
- Every Python command runs through `uv run` (local, npm scripts, CI).
- No CDN or external request at runtime: fonts and KaTeX CSS and fonts are copied into `dist/assets/`.
- Light and dark themes. Preference stored in `localStorage` under `tsc:theme` (never `aicourse:`: both courses share the `maxto.github.io` origin). With no stored preference, follow `prefers-color-scheme`.
- Light tokens (brand, from ai-one-token-at-a-time): `--bg #f5f6fa`, `--surface #ffffff`, `--ink #161a23`, `--ink-2 #464d5e`, `--muted #6f7689`, `--rule #dde1ea`, `--accent #3b5bdb`, `--accent-soft #edf2ff`, `--line #aeb6c6`. Dark (dimmed, from `docs/design/dark-theme.md`, no near-black): `--bg #1c2029`, `--surface #262b37`, `--ink #f2f4f8`, `--ink-2 #ccd2de`, `--muted #a3aabb`, `--rule #3e4657`, `--chip #333a49`, `--accent #8ca3ff`, `--accent-ink #0b0e14`, `--accent-soft #2c3768`, `--line #8d98b0`. Light adds `--chip #eef0f5`.
- Figure variables (dark / light): `--fig-bg #171a21` / `var(--surface)` (panel behind a figure, darker than the card in dark), `--fig-box #353c4c` / `var(--surface)`, `--fig-soft #333a49` / `var(--chip)`, `--fig-muted #ccd2de` / `var(--muted)` (small figure text and muted lines), `--fig-ghost #8d98b0` / `var(--chip)`, `--soft-mix 28%` / `16%` (tints via `color-mix(in srgb, <colour> var(--soft-mix), var(--surface))`). Figure classes map only to these and the page variables: one CSS change fixes every figure. Layers keep clear steps in dark: page < card < raised box. Small text reaches 4.5:1 on every fill it can sit on, body text 10:1.
- Type: Geist (text), Geist Mono (labels, code). Fallbacks `system-ui`, `ui-monospace`.
- Figures: SVG styled only through classes defined in `site/theme.css`. No `fill`/`stroke` colour attributes, no inline `style`, no `width`/`height` on the root. Each figure has `role="img"` and a `<title>`. Readable at 375 px.
- Prose (lesson text, captions, notes) has no semicolons and no em-dashes, outside code and math (owner's writing rule).
- Visual style: minimal, flat, 2D, low density, few colours with constant meaning (series A `ink`, series B `accent`, third group `line`).
- Fixtures are saved numbers in `fixtures/`, frozen once Task 3 passes. The generator documents how they were made. The fixture is an authored demonstration, and the lessons say so: it shows what a choice does, it is not evidence that a method performs well.
- DTW convention everywhere: local cost = squared difference, closed endpoints (0, 0) and (n−1, m−1), steps (1, 0), (0, 1), (1, 1) with no weights, Sakoe-Chiba window `|i − j| ≤ w` in samples, result = square root of the accumulated cost, no length normalisation. Course window: `w = 4` samples (2 hours at 30-minute sampling). Inputs: non-empty, finite, `w` a non-negative integer or `None` (no window), else `ValueError`.
- SBD inputs must have non-zero norm, else `ValueError` (the formula is undefined).
- Site address: `https://maxto.github.io/time-series-clustering/` (GitHub Pages, owner 2026-10-28, a custom domain may replace it later). One constant, `SITE_URL` in `scripts/build.py`, for the canonical link and Open Graph tags.
- Commits stay local. No push, no repo rename, no Pages activation without the owner's separate go-ahead for each.

## Review Focus

- **Dark theme on figures:** a figure colour fixed for the light theme vanishes in dark (seen in the mockup legend), or small labels fall under 4.5:1 on a tinted fill (happened in the other course). Pinned by the SVG validator (Task 5), the contrast check and the dark screenshots (Task 9).
- **Deployed subpath:** links or assets that work on `file://` but break under `/time-series-clustering/`. Pinned by the HTTP e2e run (Task 5).
- **DTW and SBD inputs outside the contract:** no admissible path, empty or non-finite input, constant series in SBD. Pinned in Task 2 (groups A, C).
- **Clustering returns fewer groups than asked:** `maxclust` can merge at ties. Pinned in Task 3 (group E).
- **Numbers in the text drifting from the code:** pinned by generated numbers (Task 6) that the build substitutes, never copied by hand.
