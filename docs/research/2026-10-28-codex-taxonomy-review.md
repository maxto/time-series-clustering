**1. Taxonomy: useful vocabulary, unsuitable as a mutually exclusive hierarchy**

Keep shape, features and models as approachable entry points. Replace the tree with a pipeline: **object → preprocessing → representation → comparison → grouping → validation**. Add an independent “differences to preserve or ignore” axis. A fitted AR coefficient vector is both model-derived and a feature representation. An embedding can be compared with Euclidean distance. A model-based mixture can cluster directly without first constructing pairwise distances. These are different decisions.

Paparrizos et al., *A Survey on Time-Series Distance Measures* (2024 preprint), separates lock-step, sliding, elastic, kernel, feature-based, model-based and embedding measures. Use that as the atlas's navigation, not a claim that all seven sit at the same conceptual level. It covers over 100 measures, which is also a reason not to promise exhaustiveness. [Paper](https://arxiv.org/abs/2412.20574).

Concrete corrections to the [current README](https://github.com/maxto/Time-Series-Clustering/blob/master/README.md):

| Location | Verdict and precise correction |
|---|---|
| Lock-step “Cross-correlation”, elastic “SBD” | **WRONG placement.** Put lag-optimised cross-correlation and SBD under sliding/global alignment. Distinguish a single global shift from DTW's local warping. State normalization, lag bounds and padding conventions. SBD and k-Shape are respectively a comparison and a clustering algorithm. [Paparrizos & Gravano, 2017 expanded paper](https://www.paparrizos.org/papers/PaparrizosTODS17.pdf). |
| Elastic “Shapelets/U-Shapelets” and “GAK” | **MIXED levels.** Shapelets describe local patterns or a representation. GAK is a kernel similarity, not a distance interchangeable with DTW. Give kernels their own route to compatible clustering. The current R mapping also overlooks the GAK-derived distance already documented by [dtwclust](https://cran.r-project.org/package=dtwclust). |
| Binary = Hamming, `dist(method="binary")` | **WRONG.** R uses asymmetric binary/Jaccard-style distance, treating nonzero values as present. It is not general categorical Hamming distance. Correct the row or exclude categorical sequences from the core. [R documentation](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/dist.html). |
| General schema: KNN under partitioning | **WRONG.** Nearest-neighbour search/classification is not a clustering algorithm by itself. Remove it. A nearest-neighbour graph can instead be an input to an explicitly named graph clustering method. |
| Structure-based, especially the trailing compression subtree | **MISLEADING.** Do not nest CID and permutation-pattern comparison under compression. Separate complexity corrections, ordinal-pattern distributions, model comparisons and compression estimates. “Structure” is too broad to teach a mechanism. |
| Clustering and validity lists | **MISSING compatibility constraints.** An ordinary arithmetic-mean k-means update does not become appropriate by changing its distance argument. Explain distance-specific barycentres and medoids. Ward, centroid and median linkage require Euclidean geometry. CH/DB scores on feature vectors are not generic scores for a DTW matrix. [SciPy linkage constraints](https://docs.scipy.org/doc/scipy/reference/generated/scipy.cluster.hierarchy.linkage.html), [tslearn barycentres](https://github.com/tslearn-team/tslearn/blob/main/docs/user_guide/dtw.rst). |

Organise the reader's choices around meaning:

- **Level and amplitude:** does a large signal belong with a small one of the same shape? Per-series z-normalization removes potentially important information. Define constant-series handling.
- **Clock time versus timing variation:** is a peak at 08:00 different from one at 20:00? Is a slower execution of the same movement equivalent? Global shifting, circular shifting and local warping answer different questions. Distinguish exact invariance from approximate tolerance under stated assumptions.
- **Local versus global evidence:** a short diagnostic motif may matter more than the rest of a recording. Clustering whole recordings using shapelet features is still whole-series clustering. Clustering overlapping windows, motif discovery and segmentation are distinct tasks.
- **Channels and sampling:** dependent multivariate DTW shares one alignment across channels. Independent channel alignment can destroy meaningful synchrony. Cover channel units/weights, timestamps, unequal lengths, missingness and resampling. Basic DTW on array positions does not automatically handle irregular physical time.
- **Learned representation:** separate an autoencoder or self-supervised encoder followed by clustering from jointly trained deep clustering. Augmentations impose assumptions about what should remain similar. Foundation-model embeddings belong in an outlook, not in a claim of superior clustering.

Three evidence updates should change the proposed course:

1. **Elastic alternatives deserve space beside DTW.** Holder, Middlehurst & Bagnall, *A review and evaluation of elastic distance functions for time series clustering* (2024 journal issue, online 2023), compared nine elastic measures with k-means/k-medoids on UCR datasets. MSM and TWE performed particularly well, and k-medoids improved results across the studied distances. This supports teaching edit-based alternatives, not declaring MSM universally best. [Paper](https://eprints.soton.ac.uk/489950/1/s10115-023-01952-0.pdf).
2. **A 2026 account must include improved centroid methods.** Holder & Bagnall, *Rock the KASBA* (2026), combines consistent elastic initialization, barycentre updates and metric-based pruning. It reports competitive quality and substantial speed gains in its experiments. Include it as a modern case study, with dataset and runtime bounds, rather than freezing “medoids beat means” into a rule. [Paper](https://doi.org/10.1007/s10618-026-01189-9).
3. **Multivariate comparison needs its own lesson.** d'Hondt et al., *A Structured Study of Multivariate Time-Series Distance Measures* (SIGMOD/PACMMOD 2025), investigates distance families and normalization across classification, clustering and similarity search. It supplies a better basis than extrapolating univariate rankings to arbitrary multichannel sensors. [Author-hosted paper](https://www.paparrizos.org/papers/DhondtSIGMOD25.pdf).

Two conceptual references complete that update: Yue et al., **TS2Vec** (AAAI 2022) illustrates learned representations, but its classification evidence is not proof of clustering superiority. Cuturi & Blondel's **soft-DTW** (2017) and Blondel, Mensch & Vert's **soft-DTW divergence** (2021) explain why a differentiable loss, a dissimilarity and a metric are different objects. Raw soft-DTW can be negative and need not have zero self-cost. [TS2Vec](https://ojs.aaai.org/index.php/AAAI/article/download/20881/20640), [soft-DTW](https://proceedings.mlr.press/v70/cuturi17a.html), [divergence](https://proceedings.mlr.press/v130/blondel21a.html).

**Drop from the reading path:** the duplicated general schema, the long validity-index inventory, STING/CLIQUE, SOM, affinity propagation, generic robust continuous clustering, compression details and a full shapelet/deep-training implementation. Keep accurate entries in a reference atlas. Retain Euclidean distance as a serious baseline. “Modern” should mean better decisions and evidence, not simply more neural models.

**2. Hook: one dataset, two legitimate questions, visibly different groups**

Open with twelve clearly labelled synthetic daily electricity-demand profiles. Ask readers to group them before naming a method. Then reveal two questions: “Which days stress the grid at the same hour?” and “Which profiles have the same pattern even if their timing changes?” A third comparison shows what happens when total demand matters. No single grouping is the answer to all three.

Use that family throughout, with controlled changes in offset, scale, global lag, local duration, noise and missing observations. Do not invent one set of synthetic labels and call it universal ground truth. Add one small real-data transfer exercise at the end, selected only after checking provenance and redistribution terms. That prevents a polished synthetic example from masquerading as empirical validation.

The concrete reading rewards should be:

- A recurring four-panel figure: **series → permitted alignment → distance matrix → groups with representative curves**. Change one assumption at a time. Show when warping wrongly merges morning and evening demand.
- One optional interactive control panel for normalization, lag and warping-window width. Use precomputed results, disclose their scope, and provide a static SVG fallback. Do not build a browser numerical engine for the first release.
- A compact decision guide readers complete incrementally: object, preserved differences, candidate representation/measure, compatible grouping, failure check, runtime budget.
- A final comparison table for a few declared pipelines, including Euclidean, constrained DTW, MSM/TWE and a feature baseline. Report preprocessing, parameters, initialization, seeds, time/memory and stability. Keep literature results separate from course experiments. Never rank methods by silhouettes computed in unrelated geometries alone.

“Readers finish everything” is a weak success criterion for a reference work. A better proposed acceptance exercise is whether a reader can choose between two plausible distances, explain the assumption, reject one incompatible algorithm and reproduce a small result. Test that with a handful of target readers before expanding the atlas.

**3. Outline: 12 concept lessons, then two language labs**

Four conceptual modules plus a code appendix is enough. Aim for roughly 350–500 words per conceptual lesson, one mechanism figure, a small numerical example where useful, one failure case and one decision question. Reading-time estimates need a pilot.

| Module | Lesson | Content and figure |
|---|---|---|
| A. Define similarity | 1. Same series, different questions | The running profiles and alternative valid groupings. Define the clustering object and the task. |
| A | 2. What preprocessing erases | Raw versus normalized signals, sampling, missingness, unequal lengths, constants. |
| B. Compare sequences | 3. Compare at the same time | Euclidean/L1 and correlation, with one hand-computable example. Explain that `1-r` is not generally a metric. |
| B | 4. Slide without stretching | Cross-correlation/SBD, lag limits, boundaries and the clock-time failure case. |
| B | 5. Stretch time carefully | DTW recurrence, local cost, admissible paths and window constraints. A cost grid explains the mechanism. Soft-DTW is a short extension. |
| B | 6. Allow edits and mismatches | LCSS/EDR/ERP contrasted with MSM/TWE. Teach costs and tolerance choices, with detailed formulas in optional measure cards. |
| C. Compare representations | 7. Summarise the dynamics | ACF, spectral features, wavelets/SAX as alternatives, catch22. Raw series → features → feature scaling → distance. |
| C | 8. Compare generating behaviour | AR/model parameters and their assumptions. Distinguish distances between fitted models from mixture-based clustering. Complexity/ordinal/compression methods get an atlas pointer. |
| C | 9. Learn a representation | Autoencoders, self-supervised embeddings and joint deep clustering. Show what augmentation preserves or discards. |

Borrow the reference course's short explanations, common-mistake box, stable lesson IDs, Markdown portability and mechanism-first diagrams. **Do not copy its template literally.** Its 110–180-word deep dive and generic everyday analogy are too restrictive for recurrences and assumptions. **5. Risks and pushback**

- **Scope: high.** Forty measures × two languages × figures × benchmarks is a maintained technical reference, not a mini-course. Teach families through a few representatives. Initially implement transparent Euclidean/L1, correlation, SBD and constrained DTW kernels, plus a small feature pipeline in both languages. Put advanced implementations behind verified adapters or mark them unavailable. Do not promise reference code for every atlas entry.
- **Correctness: high.** Each detailed measure card needs its exact formula/recurrence, local cost, boundary conditions, normalization, admissible input, parameters, invariance limits, computational cost and original reference. Package names and signatures alone are insufficient. LCSS tolerance, DTW step weights and squared-versus-rooted outputs can change results substantially.
- **Cross-language equivalence: high.** Save shared numeric fixtures rather than assuming identical random seeds generate identical data. Include hand-computable distances, constant series, unequal lengths, zero lag, constrained paths and ties. Match z-score degrees of freedom, output scaling and tie policy. Compare distances within a stated tolerance and partitions independently of cluster-label numbering. Library agreement is supporting evidence, not the sole oracle.
- **Benchmark interpretation: high.** UCR class labels are an external comparison target, not proof of the uniquely correct unsupervised grouping. If k is supplied from class counts, label that an oracle-assisted protocol. Prevent label-driven tuning and entity leakage across overlapping windows. A small course example cannot establish a universal winner. Prefer a few reproducible comparisons over a leaderboard.
- **Scale: material.** For N series of length T, a dense pairwise matrix already requires O(N²) storage, and unconstrained pairwise DTW can cost O(N²T²). Explain windows, subsets, feature routes and distance-on-demand. Educational kernels must not be advertised as production implementations.
- **Existing audience: preserve the useful asset.** Keep the repository URL and quick-reference entry point. Add the course link above the corrected tables, preserve major anchors and retain a clearly dated legacy reference/PDF. The repository's default branch is currently `master`, verified through GitHub, so a copied Pages workflow must not silently assume `main`. Do not move the list to an unrelated repository merely to launch the course.
- **Licensing: decide before publication.** The request reports no licence, and the inspected README contains no grant. Public visibility does not itself supply general reuse rights. The existing course's MIT-code/CC-BY-content split is a sensible proposal for original material, with explicit treatment of code blocks. Check ownership/contributions, dataset terms, third-party figures and the PDF separately. Do not relabel copied GPL implementations as MIT. [GitHub licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).
